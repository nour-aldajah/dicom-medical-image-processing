# DICOM Medical Image Processing

## About the project
This project explores several image processing techniques on a medical image in DICOM format. It displays the original image and compares it with processed versions.

The notebook applies histogram equalization, intensity windowing, CLAHE contrast enhancement, and Sobel edge detection.

## What I learned
I practiced loading DICOM images, working with pixel data, applying image enhancement techniques, and visualizing the results.

## Tools used
Python, pydicom, NumPy, OpenCV, and Matplotlib.

## Requirements
The notebook requires the DICOM image file `1-008.dcm`. The image is not included in this repository.

## Important note
This is an educational image processing project, not a medical diagnostic tool.
